# LINEAR DESIGN PRINCIPLES FOR SWASTHYATRA

Linear is used as a UX architecture reference, not a visual clone.

## Extracted principles

- Dense information hierarchy
- Fast keyboard-first navigation
- Focused work surfaces
- Low-friction transitions between context and action
- Status visible without dashboard noise
- Operational tables and ledgers over decorative cards

## Application

Use Linear principles for:

- Sidebar navigation
- Command palette
- Journey ledger
- Provider network list
- Escalation queue
- Activity feed
- Dashboard layout

## Avoid

- Copying Linear's visual identity
- Blue-heavy SaaS gradients
- Generic issue tracker styling
- Large decorative hero blocks without context

## Quality test

Every page should answer within 2 seconds:

1. What is happening?
2. What requires attention?
3. What happens next?
