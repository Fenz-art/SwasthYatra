# SWASTHYATRA FRONTEND DOCTRINE — WORLD CLASS UI/UX REBUILD

You are not redesigning a healthcare dashboard.

You are designing the operating system for a Healthcare Navigation Network.

The current platform already contains:

* Patient OS
* Doctor OS
* Pharmacist OS
* Hospital OS
* Organization OS
* Operator OS
* Agent OS
* Provider Network
* Communication Network
* Outcome Intelligence

Do NOT redesign workflows.

Do NOT simplify architecture.

Do NOT remove functionality.

Your mission is to elevate the entire frontend to world-class product quality.

The result should feel like:

* Linear's information architecture
* Cursor's agent experience
* Raycast's interaction model
* Stripe's trust and documentation quality
* Notion's readability
* Airtable's operational power
* Tsenta's visual craft and storytelling

while remaining completely original.

---

# CRITICAL RULES

Avoid anything that looks:

* Vibecoded
* Generic
* Template-generated
* Bootstrap-like
* Admin-dashboard-like
* Shadcn demo-like
* Dribbble-inspired

Do not create:

* Oversized cards
* Huge empty spaces
* Excessive gradients
* Floating random animations
* Decorative effects without purpose

Every visual decision must support:

* Information density
* Clarity
* Intelligence
* Trust
* Operational efficiency

The product should feel expensive.

Not flashy.

---

# DESIGN NORTH STAR

The application should feel like:

"Cursor for Healthcare Operations"

not

"Healthcare SaaS Dashboard"

The user should feel:

The system is alive.

The system is thinking.

The system is coordinating.

The system is working on their behalf.
